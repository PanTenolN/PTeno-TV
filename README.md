# PTeno TV

Безкоштовне вебменю українською для телевізорів Sharp із TiVo OS та URL Loader.

## Що вже є (версія 0.1)

- Плитки YouTube (Invidious), Twitch, Google
- Пошук відео та вебсторінок
- Налаштування адрес Invidious/Twitch зі збереженням у localStorage, якщо телевізор підтримує
- Навігація стрілками й OK, закриття панелей кнопкою Back/Escape
- Темна тема без власних рекламних банерів та аналітики

**Перевірено на телевізорі:** URL Loader відкриває HTTPS, а Invidious `https://inv.nadeko.net/` відтворює відео на Sharp 32HE2245I.

**Потребує перевірки:** робота самого PTeno TV у URL Loader, Twitch, Google та керування пультом. Головне меню TiVo OS не замінюється.

## TV-режим 0.2 (експериментально)

Головна сторінка `index.html` веде на `tv.html?service=youtube` та `tv.html?service=twitch`.

- **YouTube:** виконує пошук через публічний Invidious API, показує результати та пробує відтворити MP4 потоком у вбудованому HTML5-плеєрі. У разі проблем із CORS, API або відеокодеком є кнопка звичайного Invidious.
- **Twitch:** завантажує офіційний Twitch Player SDK для введеної назви каналу, намагається керувати ним кнопками PTeno TV (Play, Pause, звук). Для деяких телевізійних браузерів SDK, iframe, cookie або DRM можуть бути недоступні; у такому разі є резервна кнопка звичайного Twitch. Twitch-реклама не блокується.
- **Керування:** стрілки, OK, Back у нашому вебінтерфейсі. Коли переходиш на зовнішній сайт, PTeno TV не контролює його курсор.
- **Безпека:** лише HTML/CSS/JavaScript; без системного доступу, без перепрошивки, без введення паролів у PTeno TV.
- **Статус:** код JavaScript перевірено на синтаксис, але роботу саме на Sharp 32HE2245I треба перевірити руками. Відкрий `https://pantenoln.github.io/PTeno-TV/?v=2` після оновлення GitHub Pages.

## Безкоштовна публікація через GitHub Pages

1. Відкрий Settings → Pages цього репозиторію.
2. У **Build and deployment** вибери **Deploy from a branch**.
3. Вибери гілку **main**, теку **/(root)** і натисни **Save**.
4. Після публікації відкрий `https://pantenoln.github.io/PTeno-TV/`.
5. Якщо сторінка працює у браузері, введи ту саму адресу в URL Loader на телевізорі.

## Зауваження

Це звичайний вебзастосунок (HTML/CSS/JS), **не прошивка TiVo OS**. Він не видаляє системні рекламні рекомендації, не встановлює APK і не замінює системний лаунчер. Працездатність альтернативних відеосервісів залежить від їх серверів і можливостей браузера телевізора. Не вводь паролі або токени в довільні дзеркала Invidious.

## Версія 0.3 — підказки пошуку

- **YouTube:** під полем пошуку з'являються підказки, коли вводиш щонайменше два символи. Спочатку показуються попередні пошуки, потім — онлайн-підказки Google Suggest (резерв: Invidious API). Онлайн-підказки не гарантуються: це неофіційний зовнішній інтерфейс, який може бути недоступним у TiVo; введені запити надсилаються зовнішньому сервісу.
- **Twitch:** автопідказки за збереженими назвами каналів, які відкривалися через PTeno TV на цьому телевізорі. Пошуку по всій базі Twitch немає: офіційний Twitch API потребує авторизації.
- **Пульт:** ↑↓ змінюють активну підказку; OK вибирає та запускає пошук/канал; Back/Escape закриває список.
- **Збереження:** лише у localStorage поточного браузера (якщо доступно). Для очищення історії можна видалити дані сайту в браузері.
- **Оригінальний YouTube:** додано посилання на офіційний вебсайт для порівняння, але **в ньому рекламу не заблоковано**. Через URL Loader неможливо встановити uBlock Origin або змінити офіційний додаток TiVo OS; власні HTML-скрипти PTeno TV не мають доступу до сторінок/додатків іншого походження.

Відкрити тестовий режим: `https://pantenoln.github.io/PTeno-TV/tv.html?service=youtube&v=3`.

## Версія 0.4 — підказки для пульта та PTeno Shield

- **Після клавіатури:** список підказок не закривається автоматично після втрати фокусу. Він розташований під полем. Кнопка «↓ Вибрати підказку пультом» переводить фокус у список, далі стрілки та OK.
- **Twitch:** схожі назви з підказок Google для запиту «twitch <текст>» (лише можливі логіни каналів) і локальна історія. Вони не підтверджені Twitch, можуть бути недоступні на TV.
- **PTeno Shield:** для нашого HTML5-програвача Invidious додано перемикач автоматичного пропуску категорій `sponsor` і `selfpromo` за відкритою базою [SponsorBlock](https://sponsor.ajay.app/). Режим зберігається локально. При вмиканні ID відео передається SponsorBlock для отримання таймкодів. Якщо API недоступний, відтворення продовжується без пропуску.
- **Локальний фільтр:** рекламно позначені елементи відкидаються з результатів Invidious у нашому інтерфейсі.
- **Обмеження:** це не розширення uBlock Origin. PTeno TV не може перехоплювати рекламу офіційного YouTube/Twitch, а також рекламу всередині Twitch iframe. Реклама Twitch **не заблокована**. PTeno TV не вставляє власних рекламних банерів.

**Перевірка на телевізорі:** відкрий https://pantenoln.github.io/PTeno-TV/?v=4, введи назву, закрий клавіатуру, вибери підказку. Повтори для Twitch. Увімкни відео й протестуй PTeno Shield. Синтаксис JS перевірено, але фактичну роботу на Sharp потрібно підтвердити.

## Основний YouTube — офіційний сайт

На прохання власника PTeno TV головна плитка YouTube відкриває офіційний вебсайт `https://www.youtube.com/tv`, а пошук через головне меню спрямовує на `https://www.youtube.com/results?search_query=...`. Якщо телевізійна вебверсія не підтримується в URL Loader, можна відкрити встановлений у TiVo OS оригінальний YouTube безпосередньо з системного меню телевізора. **Це не запуск нативного застосунку TiVo через наш HTML:** підтвердженого механізму deep link у нас немає.

Реклама в офіційному YouTube **не блокується** через PTeno TV або PTeno Shield: сайт PTeno TV не має доступу до коду та мережевих запитів іншого вебпоходження або офіційного застосунку. Пункт TV-режиму в `tv.html` з Invidious залишається як додатковий необов’язковий варіант.
